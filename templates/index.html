      myNotes Folder

      Choose the folder where all your notes and attachments will be stored. You can use any local or cloud-synced folder (OneDrive, Dropbox, etc.). Attachment sub-folders (images, documents, archives, videos) are created automatically. This path is saved per-machine in the app config, so it can differ between computers.

      Step 1 of 4 — Get Telegram API Keys

      To connect myNote to your Telegram account you need a personal API ID and API Hash. This is free and takes about 2 minutes:

      1. Click to open it in your browser
      2. Log in with the phone number you use for Telegram
      3. Click API development tools
      4. Fill in App title (e.g. myNote) and Short name (e.g. mynote) — any values work
      5. Click Create application
      6. Copy the App api_id and App api_hash shown on that page
      Step 2 of 4 — Verify Your Phone

      Telegram just sent a login code to your Telegram app on your phone or desktop. Open Telegram and look for a message from Telegram.

      If you have two-factor authentication (2FA) enabled you will be asked for your 2FA password after entering the code.

      Step 3 of 4 — Create Your Private Channel

      myNote saves messages and files sent to a private Telegram channel as notes. Create a dedicated channel now:

      1. Open Telegram on your phone or desktop
      2. Tap the compose / pencil icon → New Channel
      3. Name it myNotes (or any name you like)
      4. Select Private Channel
      5. Skip adding subscribers and tap Create
      6. Send a test message to the channel so it appears in the list

      Already have a channel you want to use? Just click Browse below.
